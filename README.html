// Features

핵심 기능

⚡

병렬 웹 검색

Goroutine Worker Pool로 쿼리 6개를 동시에 검색. 순차 대비 최대 101배 빠름.

🔍

신뢰도 필터링

차단 도메인 제거 + Tavily Score 기반 필터링으로 검증된 출처만 사용.

📄

리포트 자동 생성

Gemini가 검증된 검색 결과를 마크다운 리포트로 합성. 출처 URL 포함.

🤔

Human-in-the-loop

리포트 확인 후 승인하면 카드뉴스 생성. 자동화와 사람의 판단을 결합.

🃏

카드뉴스 생성

리포트 핵심을 6장의 HTML 카드뉴스로 자동 변환. 브라우저에서 바로 열림.

📊

성능 추적

벤치마크 결과와 검색 품질 점수를 자동으로 markdown에 누적 기록.

// Architecture

아키텍처

사용자 입력 (topic) │ ▼ Agent (ReAct 루프) │ ├─ [1/4] Gemini → 쿼리 6개 생성 │ ├─ [2/4] Orchestrator │ ├── Goroutine 1 → Tavily Search │ ├── Goroutine 2 → Tavily Search ← 동시 실행 │ ├── Goroutine 3 → Tavily Search │ └── Channel로 결과 수집 │ ├─ 신뢰도 필터링 (차단 도메인 + Score < 0.7 제거) │ ├─ [3/4] Gemini → 마크다운 리포트 생성 │ └─ [4/4] Gemini → 카드 데이터 추출 (JSON) │ ── Human Review ── (y/n 승인) │ y ▼ HTML 카드뉴스 생성

// Tech Stack

기술 스택 & 설계 결정

Go Goroutine으로 병렬 검색 구현. Python의 GIL 없이 동시성 처리. 단일 바이너리 배포로 어디서나 실행 가능.
Gemini 2.5 Flash 무료 티어 (1,500회/일). 쿼리 생성 · 리포트 작성 · 카드 추출 세 가지 역할로 활용.
Tavily API AI 친화적 검색 결과 제공. Score 기반 품질 필터링으로 신뢰도 낮은 결과 자동 제거.
Worker Pool 고정 개수 Goroutine이 Channel에서 작업을 꺼내 처리. 리소스 제어와 동시성을 동시에 달성.
ReAct Pattern Reasoning + Acting 루프 구현. 쿼리 생성 → 검색 → 종합의 에이전트 사이클을 코드로 구현.
